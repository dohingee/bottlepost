# 앱 이름: 보틀포스트 (Bottlepost)

**확정.** "유리병 편지(bottle) + 우편(post)". 낯선 이에게 띄운 편지가 어딘가의 누군가에게 닿는다는 컨셉을 그대로 담고, 영어권·아시아권 모두 발음하기 쉽습니다.

- 같은 이름의 앱이나 상표는 검색되지 않았습니다.
- 비슷한 컨셉의 경쟁 앱: Bottled (Honi Inc.), BottleTalk, Drift Bottle, BottleApp, MessageMap.

- 작업 환경에서 Play 스토어에 접속할 수 없어 **스토어 내부 검색은 직접 해야 합니다.**

## 출시 전 직접 확인할 것
1. Play 스토어에서 "Bottlepost", "Bottle Post", "보틀포스트" 검색
2. 상표 검색: KIPRIS(한국), USPTO(미국), EUIPO(EU) — 9류(소프트웨어), 38류(통신), 45류(소셜·만남 서비스)
3. 도메인: bottlepost.app / bottlepost.co 등
4. 필요하면 상표 출원(한국 특허청 전자출원)
