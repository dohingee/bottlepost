# 계정 요청 처리

## 복원 문의
1. 구글 연결 여부 확인: `npx tsx tools/account-cli.ts find-email <email>` (연결 계정만 조회됨)
2. 결과별 안내
   - 연결 계정 있음 + `hasBackupKey=true`: 새 기기에서 첫 화면 "전에 쓰던 계정이 있어요 — 구글로 복원" → 드라이브 권한 허용
   - 연결 계정 있음 + 백업 없음: 계정은 복원되지만 대화는 없음(백업은 Wi‑Fi에서 하루 1회 자동, 설정에서 수동)
   - 조회 안 됨: 익명 계정이었다면 복구 불가. 솔직히 안내하고 다음엔 구글 연결 권장
3. 서버에는 편지 본문이 없으므로 "서버에서 복구"는 불가능하다.

## 삭제 요청 (Play 정책: 앱 내 + 웹 + 문의)
1. 앱 내: 설정 > 계정 삭제 / 웹: `https://<도메인>/delete-account` (구글 연결 계정)
2. 이메일 요청: 요청 메일 주소의 해시로 `find-email` → 본인 확인(해당 구글 계정에서 보낸 메일인지) → 운영자 승인 → `delete <uid> --yes`
3. 7일 안에 처리하고 완료를 회신한다.

## 관리자 권한
`grant-admin <uid>` / `revoke-admin <uid>` — 운영자 본인 지시가 있을 때만. 부여 내역을 운영 기록에 남긴다.
